# 简历格式规范（WXX 简历模版）

> 本规范由对用户模板 `assets/简历模版.docx` 的深度 XML 解析提取而来。
> 生成简历时必须严格遵循本规范，保证输出与模板排版一致。

| 上边距 | 1cm（567 twips） | |
| 下边距 | 1cm（567 twips） | |

## 2. 字体规范

| 用途 | 中文字体 | 西文/数字字体 | 字号 | 加粗 |
|---|---|---|---|---|
| 姓名 | 宋体 | 宋体 | 14pt（sz=28） | 加粗 |
| 基本信息行（性别/年龄） | 宋体 | 宋体 | 10.5pt（sz=21） | **不加粗** |
| 联系方式行（手机/邮箱） | 宋体 | Times New Roman | 10.5pt（sz=21） | 不加粗 |
| 求职意向行 | 宋体 | Times New Roman | 10.5pt（sz=21） | 不加粗 |
| 分区标题 | 宋体 | 宋体 | 13pt（sz=26） | 加粗 |
| 条目行（学校/公司/项目名+角色） | 宋体 | 宋体 | 12pt（sz=24） | 加粗 |
| 条目右侧时间 | 宋体 | 宋体 | 10.5pt（sz=21） | **不加粗** |
| 正文（描述/职责/成果） | 宋体 | 宋体 | 10.5pt（sz=21） | 不加粗 |
| 列表项（悬挂缩进） | 宋体 | 宋体 | 10.5pt（sz=21） | 不加粗 |

字体设置要点：
- **只有联系方式和求职意向**的西文用 `Times New Roman`，其余全部用 `宋体`（中文+西文统一宋体）。
- 字号以 twips 半磅值表示：sz 28=14pt、sz 26=13pt、sz 24=12pt、sz 21=10.5pt。

## 3. 字符间距（w:spacing，run 级别）

| 位置 | w:spacing 值 | 实际效果 |
|---|---|---|
| 姓名行 | 4 | 加宽 0.2pt |
| 基本信息行 | 4 | 加宽 0.2pt |
| 联系方式行 | 9 | 加宽 0.45pt |
| 求职意向行 | 9 | 加宽 0.45pt |
| 其余正文 | 无 | 标准间距 |

## 4. 段落间距与行距

所有段落统一：**单倍行距**（w:spacing line=240 lineRule=auto）。

| 段落类型 | 段前 | 段后 | 对齐 |
|---|---|---|---|
| 姓名行 | 2.1pt（42 twips） | 0 | 居中 |
| 基本信息行 | 2.2pt（44 twips） | 0 | 居中 |
| 联系方式行 | 2.2pt（44 twips） | 0 | 居中 |
| 求职意向行 | 2.2pt（44 twips） | 0 | **居中** |
| 求职意向后空段落 | 2.2pt（44 twips） | 0 | 默认（有 firstLine=2178 firstLineChars=1100 缩进） |
| 首个分区标题 | 0 | 0.5行（after=159, afterLines=50） | 左对齐 |
| 后续分区标题 | 0.5行（before=159, beforeLines=50） | 0.5行（after=159, afterLines=50） | 左对齐 |
| 经历条目行 | 0 | 0 | 左对齐（时间靠右对齐制表位推到行尾） |
| 正文/列表项 | 0 | 0 | 左对齐 |

## 5. 分区标题下划线

每个分区标题段落底部有一条**黑色单线**：

```
w:pBdr → w:bottom → val=single, sz=4（0.5pt）, space=0, color=000000
```

## 6. 经历条目行布局

条目行格式：`左侧名称（加粗12pt 全宋体） + [居中角色名（加粗12pt）] + 右对齐时间（10.5pt 不加粗 全宋体）`。

- 居中制表位位置 = 可用宽度中间 9.23cm（twips pos=5233），放角色名（如"项目负责人"/"人力资源部干事"）。
- 右对齐制表位位置 = 可用宽度尽头 18.46cm（twips pos=10466，即右边距处），放时间。
- 可用宽度 = 21 − 1.27 − 1.27 = 18.46cm（制表位相对于左边距）。
- 用户要求：角色名要在这一排居中。
- 时间**永远不加粗**（模板中所有条目时间均不加粗）。
- 教育条目无角色名，只有名称+时间。
- 示例："XX大学 XXXXXXXX学院 [制表位] 2023.09-2027.06"
- 示例："XXXXXXXXXXX [制表位] 驻场运维实习生 [制表位] 2025.10-2025.12"

## 7. 列表项（悬挂缩进 + • 前缀）

要点行使用"• "前缀 + 悬挂缩进：

```
文本前缀: "• "（U+2022 + 空格）
w:ind left=420, leftChars=0, hanging=420, firstLineChars=0
```

即：左缩进 21pt + 首行悬挂缩进 -21pt，让第二行与•后的文字对齐。**不加粗。**
用户要求：主要职责/项目成果后面跟的内容要分点，每行一个•标记。

## 8. 分区结构与内容组织

模板固定分区顺序与标题：

1. **教育经历**
   - 条目行：学校+学院（加粗12pt 全宋体）| 时间（不加粗）
   - 正文：专业 本科（排名）—— 不加粗
   - 正文：主修课程：xxx —— 不加粗（整段）
   - 正文：荣誉奖项：xxx —— 不加粗（整段）
   - 正文：资格证书：xxx —— 不加粗（整段）
2. **实习经历**
   - 条目行：公司+岗位 | 时间
   - `核心工作：`（标签**加粗**）+ 正文（不加粗）
3. **项目经历**（可有多个项目，每个项目一组）
   - 条目行：项目名（技术方向）项目角色 | 时间
   - `项目背景：`（标签**加粗**）+ 正文（不加粗）
   - `技术栈：`（标签加粗）+ 正文（不加粗）
   - `代码仓库：`（标签加粗）+ 正文（不加粗）
   - `主要职责：`（标签加粗，单独一行）
   - 各要点行（• 前缀 + 悬挂缩进，不加粗）
   - `项目成果：`（标签加粗，单独一行）
   - 各要点行（• 前缀 + 悬挂缩进，不加粗）
4. **校园经历**
   - 条目行：组织+职位 | 时间
   - `核心工作：`（标签**加粗**）+ 正文（不加粗）
5. **个人技能**
   - `1.专业技能：`（标签**加粗**）+ 正文（不加粗）
   - `2.综合素质：`（标签**加粗**）+ 正文（不加粗）

页首个人信息区（顺序固定）：
```
姓名（居中，14pt 加粗，全宋体，字符间距4）
性别：女/男 | 年龄：xx（居中，10.5pt 不加粗，全宋体，字符间距4）
手机号：xxx | 邮箱：xxx@qq.com（居中，10.5pt 不加粗，西文TNR+中文宋体，字符间距9）
求职意向：xxx（居中，10.5pt 不加粗，西文TNR+中文宋体，字符间距9）
[空段落]
```

## 10. Normal 样式设置（关键）

python-docx 默认创建的文档 Normal 样式有 `space_after=8pt` 和 `line_spacing=1.08`，且 `snapToGrid` 默认开启，会导致行间距比模板宽。生成时必须覆盖 Normal 样式：

| 属性 | 值 | 说明 |
|---|---|---|
| w:spacing after | 0 | 段后间距=0（默认8pt会导致段落间距宽） |
| w:spacing before | 0 | 段前间距=0 |
| w:spacing line | 240 | 单倍行距 |
| w:spacing lineRule | auto | |
| **w:snapToGrid** | **0** | **不对齐到文档网格（关键！否则行高被网格 linePitch=312 拉到15.6pt）** |
| w:autoSpaceDE | 0 | 禁用自动中英文间距 |
| w:autoSpaceDN | 0 | 禁用自动中文数字间距 |
| w:adjustRightInd | 0 | 禁用自动右缩进调整 |
| w:kinsoku | 0 | 禁用日文禁则 |
| w:kern | 0 | 禁用字距调整 |
| w:rFonts | 宋体（全） | Normal 样式默认字体 |
| w:sz | 21 | 10.5pt |

## 11. 生成要求

- 输出格式：`.docx`（Word/WPS 兼容）。
- 使用 `scripts/build_resume.py` 生成，内容以 JSON 形式传入（结构见 `scripts/resume.example.json`）。
- 模板副本位于 `assets/简历模版.docx`，可作为基准对照。
